# Cheatsheet

Senior-engineer reference guides — deep enough for production work, structured enough for interview prep. Each guide follows the same format: plain-language **Definitions**, **Where it's used**, mermaid diagrams for anything with a flow or a shape, tables for comparisons, a debugging playbook, and a tricky-interview-questions section.

## How to read a guide

Skim the mind map / table of contents first to get the skeleton, then read section by section. Jargon and abbreviations get a short definition the first time they appear, so you shouldn't need to leave the page to look something up.
